## 📌 Descrição
O **Vôlei dos Crias** é um site criado para facilitar o cadastro de atletas e a realização de sorteios de times de vôlei de um grupo em que participo. Ele permite adicionar jogadores com uma nota de desempenho (de 0 a 5 estrelas) e, em seguida, sortear times de forma equilibrada.

---

## 🚀 Funcionalidades

### 🔹 1. Cadastro de Atletas
✔ O usuário pode cadastrar atletas informando o **nome** e a **quantidade de estrelas** (0 a 5).  
✔ O sistema armazena os atletas em uma lista e exibe os jogadores cadastrados.  
✔ Validação para impedir a inserção de dados inválidos.  

### 🔹 2. Configuração do Sorteio
✔ O usuário pode definir:  
&nbsp;&nbsp;&nbsp;&nbsp;📌 **Número de times** desejado.  
&nbsp;&nbsp;&nbsp;&nbsp;📌 **Número de jogadores por time**.  
✔ O site impede sorteios impossíveis (exemplo: mais jogadores do que o total de cadastrados).  

### 🔹 3. Sorteio de Times
✔ O sistema embaralha a lista de atletas e os distribui igualmente entre os times.  
✔ Os times são exibidos com os nomes dos jogadores e suas respectivas estrelas.  

### 🔹 4. Alternar Tema (Claro/Escuro)
✔ O botão **"Tema Escuro"** permite alternar entre o modo claro e escuro.  
✔ Todos os elementos do site se adaptam automaticamente ao tema escolhido.  
✔ A interface responsiva melhora a experiência do usuário em diferentes dispositivos.  

---

## 🛠 Tecnologias Utilizadas
- 🏗 **HTML**: Estrutura do site.  
- 🎨 **CSS**: Estilização, incluindo temas claro e escuro.  
- ⚙ **JavaScript**: Lógica do cadastro, sorteio de times e troca de tema.  

---

## 📖 Como Usar
1️⃣ Abra o arquivo `index.html` ou site [] em um navegador.  
2️⃣ Cadastre os atletas preenchendo nome e estrelas, depois clique em **"Adicionar Atleta"**.  
3️⃣ Defina o número de times e jogadores por time.  
4️⃣ Clique em **"Sortear Times"** para gerar os times.  
5️⃣ Utilize o botão **"Tema Escuro/Claro"** para mudar o tema da interface.
